# Pink World Tweaks

Pokémon Pink's changes to the world for Gen1Recomp (Yellow). Needs
**pink_partner** and **pink_species**.

- Map edits on 30 maps: two new Cut trees (Route 4, Fuchsia City), Pokémon
  Mansion ledges that read as ledges, the Silph Co. 11F spot, signs and route
  details. Only the changed cells are applied, to your own imported maps.
- 28 tileset blocks redefined, two walkable-tile fixes, four new Cut-tree pairs.
- Fly from the Celadon Dept. Store and Celadon Mansion roofs (both count as
  outdoor maps, so Teleport works there too).
- The Linking Cable is sold on Celadon Dept. Store 4F.
- A reachable Full Restore on Vermilion Dock replaces Yellow's unreachable
  Safari Zone Gate Nugget.
- More caves and buildings use the dungeon battle intro (Mansion, Victory
  Road, Power Plant, Diglett's Cave, Silph Co. 9F-11F, Seafoam, Rocket Hideout).

`world_data.lua` is generated by `tools/gen_world_data.py`; don't hand-edit it.
Tile art changes are in **pink_tilesets**; scripted changes (S.S. Anne,
Hall of Fame heal, Silph Co. warp, Game Corner prizes, trades) are still to come.
