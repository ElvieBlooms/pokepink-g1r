# Pink Species

Pokémon Pink's species changes for Gen1Recomp (Yellow). Needs **pink_partner**.

- Clefairy (your partner) gets Pink's learnset, which follows Pikachu's
  progression, and can learn TM39 Swift and HM03 Surf. With Surf it can play
  the surfing minigame.
- **Linking Cable** (Yellow's unused item slot): a consumable that evolves
  Kadabra, Machoke, Graveler and Haunter like an evolution stone. It's sold
  at the Celadon Dept. Store once pink_world_tweaks is in; the normal trade
  evolution still works too.

`species_data.lua` is generated by `tools/gen_pink_data.py`; don't hand-edit it.
