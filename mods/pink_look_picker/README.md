# Pink Look Picker

A cart extra for the Pokemon Pink cart, not part of Pokemon Pink itself.

At NEW GAME, just before Oak asks your name, he asks whether you'd like to
pick your look. YES opens PRISM, the menu shared by Facets, Emerald Lens and
Crystal Lens (or the one mod's own screen if only one is loaded). Back out
of it and Oak carries on, showing you in your new look.

- With none of those mods loaded, Oak doesn't ask.
- **ASK AT NEW GAME** (Mods manager) turns the question off.
- PRISM stays in the START menu for later changes.

Needs `engine_internals`: PRISM is made by those mods in the START menu's
item hook, so this asks for it the way the START menu does.
