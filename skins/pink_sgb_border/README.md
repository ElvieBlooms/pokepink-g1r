# Pokémon Pink border

Pokémon Pink's Super Game Boy border as a gen1recomp skin. The game sits in the
middle, where a Super Game Boy would put it.

A cart can't carry a skin, so this ships next to the cart as its own zip.
Install it from the launcher's **SKINS** tab (Import, or drop the zip on the
tab), then pick it like any other skin.

The skin has no touch buttons. It's made for desktop, handhelds and
controllers; on a phone using touch controls, choosing it hides the on-screen
buttons.

## What's in it
- The Clefairys and the FAIRY bubbles are jcferggy's, from Pokémon Pink, shipped
  with his permission and not covered by the MIT license.
- The frame, the POKéMON and PINK lettering, the Poké Balls, the sparkles and
  the bubble tails are new drawings by ElvieBlooms. Pink's border shares these
  pieces with Yellow's, so they were redrawn and none of Yellow's pixels ship.

`img/border.png` is made by `tools/gen_sgb_border.py` from Pink's source, at 8x
so it stays sharp when the engine scales it.
